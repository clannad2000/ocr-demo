# 英文文字抹除工具设计与使用说明

## 定位

`pipeline.erase`是五步流程中唯一负责英文擦除的模块。公开入口为：

```powershell
python -m pipeline erase --dilate-iterations 2
```

统一入口自动读取每本书的`01-ocr/pages`，并把全部结果写入`04-erased`。无需指定
`--pages-dir`或`--output-dir`。

## 输入

每页必须存在同名文件：

```text
page-NNNN.png
page-NNNN.json
```

JSON中的`layout.content`必须包含DeepSeek-OCR的文本和0–1000归一化坐标。模块不运行
PaddleOCR、Tesseract或其他补充OCR；没有被DeepSeek定位的文字不会被处理。

目录模式在任何PNG缺少同名JSON时于写入前停止，防止产生不完整批次。

## 输出

每页生成：

| 文件 | 内容 |
|---|---|
| `page-NNNN.cleaned.png` | 擦除英文后的页面，供PDF写入器使用 |
| `page-NNNN.mask.png` | 实际修复的二值掩码 |
| `page-NNNN.debug.png` | 区域和掩码调试图 |
| `page-NNNN.adjusted.json` | 区域分类、像素坐标和处理状态 |

输入PNG和页面JSON保持不变。

## 算法

1. 解析`<|ref|>...<|/ref|><|det|>...<|/det|>`区域；
2. 把归一化坐标转换为原图像素坐标；
3. 默认排除页面底部居中的独立纯数字页码；
4. 在文字框周围估计局部背景颜色；
5. 综合Lab颜色距离和灰度差提取文字候选；
6. 使用形态学操作去噪，并按`dilate_iterations`扩张抗锯齿边缘；
7. 通过OpenCV Telea或Navier–Stokes局部修复背景。

掩码只允许存在于当前文字框的扩展区域，避免跨气泡或跨图形扩散。

## 统一入口参数

| 参数 | 默认值 | 说明 |
|---|---:|---|
| `--dilate-iterations` | `2` | 字形边缘膨胀次数 |
| `--remove-page-number` | 关闭 | 同时擦除底部独立页码 |

更底层的颜色距离、背景差、padding和inpaint算法参数仍由内部模块保留，但不作为五步
生产入口的一部分。需要调试单页时应在测试或专门开发任务中调用内部模块，避免生产
命令重新引入手工路径。

## 与PDF写入的边界

`pipeline.pdf_writer`只读取cleaned PNG、锁定译文快照和坐标计划并写入中文。它不调用
本模块，不包含mask、redaction或inpaint实现，也不得自行修改译文。

## 验收

重点查看debug图和最终PDF中的：

- 彩色或描边文字是否完整擦除；
- 气泡边框、图表线和背景纹理是否被误删；
- 相邻文字框是否发生掩码串联；
- 页码是否按配置保留；
- cleaned PNG是否覆盖全部最终译文页面。

擦除成功不等于PDF视觉验收通过。最终字号、位置、遮盖和整体可读性由用户确认。
