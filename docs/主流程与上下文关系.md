# 主流程与上下文关系

## 总览

```text
1. OCR、OCR复核、DeepL翻译
2. Codex按章节进行整书翻译复核
3. 聚合裁决并锁定最终译文
4. 按DeepSeek坐标擦除英文
5. 在cleaned PNG上写入中文并生成PDF
```

## 阶段1：OCR、OCR复核、DeepL翻译

入口：`ocr_json_pipeline.py`

```powershell
python .\ocr_json_pipeline.py `
  --pdf ".\book\beast academy math guide 3A.pdf" `
  --pages "1-100" `
  --output ".\runs\study-batch-3A" `
  --mode study `
  --workers 2 `
  --verify auto
```

同一张渲染页并行进入两路视觉调用：

- `model_usage.layout_ocr`生成文字区域和0–1000坐标；
- `model_usage.primary_ocr`生成权威英文及`study.regions`。

确定性风险检查决定`--verify auto`是否调用`model_usage.ocr_verifier`。OCR复核只提供
比较证据，不自动覆盖主OCR。随后DeepL按区域ID翻译主OCR选出的自然语言区域。

主要产物：

- `pages/page-NNNN.png`；
- `pages/page-NNNN.json`；
- `manifest.json`；
- `summary.md`；
- `study.html`。

页面JSON是后续步骤的不可变机器证据。Markdown或HTML只供阅读，不是权威输入。

## 阶段2：Codex整书翻译复核

入口：`codex_book_review.py`

`plan`子命令读取用户指定的目录页图片，生成`book-review-plan.json`。`review`子命令
按计划读取每页JSON的`study.regions`，前置内容和每个正式章节各使用一个可恢复的
持久Codex任务。

```powershell
python .\codex_book_review.py review `
  --config .\ocr_config.json `
  --pdf ".\book\beast academy math guide 3A.pdf" `
  --pages-dir .\runs\study-batch-3A\pages `
  --output .\runs\book-review-3A
```

Codex读取原英文、当前译文、同章上下文、术语和按需图片，直接裁决每个区域。
结果写到`chapters/<task-id>/page-NNNN-codex-review.json`；检查点保存章节任务ID和
已完成页。原页面JSON、`manifest.json`和`study.html`保持不变。

## 阶段3：生成最终裁决文件

入口：`codex_book_finalize.py`

```powershell
python .\codex_book_finalize.py `
  --config .\ocr_config.json `
  --book-review-dir .\runs\book-review-3A
```

定稿器验证：

- 书本计划、源PDF和页面JSON的SHA-256；
- 全部`page + region id`及区域集合；
- 稀疏裁决引用的当前译文；
- 每章持久任务一致性；
- 未解决人工项。

输出：

- `book-codex-adjudication.json`：整书裁决聚合审计；
- `chapter_translation_final.json`：锁定的最终译文快照；
- `pdf_backfill_plan.json`：最终译文到DeepSeek坐标的确定性映射。

人工译文覆盖如存在，保存在独立文件中。PDF回写只允许读取锁定快照。

## 阶段4：擦除英文

入口：`erase_english_from_deepseek.py`

批量模式：

```powershell
python .\erase_english_from_deepseek.py `
  --pages-dir .\runs\study-batch-3A\pages `
  --output-dir .\runs\study-batch-3A\erase `
  --dilate-iterations 2
```

单页模式：

```powershell
python .\erase_english_from_deepseek.py `
  --image .\runs\study-batch-3A\pages\page-0030.png `
  --json .\runs\study-batch-3A\pages\page-0030.json `
  --output-dir .\runs\study-batch-3A\erase `
  --dilate-iterations 2
```

目录模式按文件名排序，要求每张PNG存在同名JSON。擦除器通过字形掩码和OpenCV局部
修复生成`page-NNNN.cleaned.png`，不写中文、不改页面JSON。

## 阶段5：写入中文PDF

入口：`pdf_translation_writer.py`

```powershell
python .\pdf_translation_writer.py `
  --config .\ocr_config.json `
  --cleaned-pages-dir .\runs\study-batch-3A\erase
```

写入器读取：

- 源PDF；
- `chapter_translation_final.json`；
- `pdf_backfill_plan.json`；
- 每个翻译页对应的`page-NNNN.cleaned.png`；
- `pdf_translation_writer.rules`和可选布局覆盖。

它只在cleaned PNG上写中文，未翻译页面从原PDF保留。写入器不执行mask、redaction、
inpaint或译文判断。程序报告通过只表示`program_checked`，最终视觉验收由用户完成。

## 上下文汇合关系

| 产物 | 直接来源 | 后续用途 |
|---|---|---|
| `page-NNNN.json` | OCR、OCR复核、DeepL | 整书Codex复核和定稿证据 |
| `book-review-plan.json` | 目录页、PDF页数、Codex | 章节边界和复核范围 |
| `page-NNNN-codex-review.json` | 页面区域、章节上下文、必要图像 | 最终裁决候选 |
| `chapter_translation_final.json` | 页面译文、Codex裁决、可选人工覆盖 | PDF回写唯一译文源 |
| `pdf_backfill_plan.json` | 锁定译文、DeepSeek坐标 | 中文放置映射 |
| `page-NNNN.cleaned.png` | 页面图、DeepSeek坐标 | 中文写入底图 |
| 中文PDF | 源PDF、cleaned PNG、锁定译文和坐标计划 | 人工视觉验收 |

## 推荐执行纪律

- 先运行各步骤的本地检查或`--dry-run`；
- 真实OCR、DeepL、Codex复核和批处理由用户执行；
- 不修改原页面JSON、`manifest.json`或`study.html`；
- 不绕过锁定快照直接回写页面JSON中的译文；
- 程序检查、可选AI抽查和人工视觉验收必须明确区分。
